# ระบบสั่งงาน AI สำหรับนักศึกษาฝึกงาน ปวช. คอมพิวเตอร์

## วัตถุประสงค์

เอกสารนี้เป็นชุดงาน/โจทย์สั่งทำงานที่ใช้ AI เป็นเครื่องมือหลัก สำหรับนักศึกษาฝึกงาน หลักสูตรประกาศนียบัตรวิชาชีพ (ปวช.) สาขาคอมพิวเตอร์ โดยมุ่งเน้น:

- ใช้ AI ฟรีเพื่อสร้างผลงานจริง
- ฝึกการสั่งงาน AI อย่างมีโครงสร้าง
- ไม่ต้องมีความรู้ภาษาอังกฤษเป็นพื้นฐาน
- มีโจทย์ให้เลือกทำมากมายและหลากหลาย
- เหมาะสำหรับนักศึกษาที่ยังไม่มีไอเดียหรือไม่รู้จะทำอะไร
- ทำผลงานที่น่าสนใจ ใช้งานได้จริง และสามารถอวดเพื่อน/อาจารย์ได้

## เป้าหมายด้านความสามารถ

นักศึกษาได้เรียนรู้และฝึกทักษะต่อไปนี้:

- การสั่งให้ AI ทำงานตามวัตถุประสงค์ที่ชัดเจน
- การปรับ prompt ให้ได้ผลงานที่ตรงความต้องการ
- การแก้ไขโค้ดและปรับปรุงฟีเจอร์
- การทดสอบและตรวจสอบความถูกต้องของผลลัพธ์
- การออกแบบ UI/UX สำหรับเว็บ/แอป
- การนำเสนอผลงานแบบมืออาชีพ
- การทำงานเป็นทีมและแบ่งหน้าที่

## การปฏิบัติที่ควรทำ

1. เลือกโจทย์ที่สนใจอย่างน้อย 1 โครงการหลัก
2. เลือกโจทย์เสริมอย่างน้อย 1 โครงการ
3. ใช้ AI เป็นผู้ช่วย ไม่ใช่คนทำแทน
4. ต้องตรวจสอบและปรับปรุงรูปแบบ/โค้ดเอง
5. ส่งรายงานภาษาไทยพร้อมภาพหน้าจอ
6. บันทึก prompt ที่ใช้และผลลัพธ์ที่ได้
7. ต้องสามารถอธิบายให้คนอื่นเข้าใจได้

- ใช้ AI เป็นเครื่องมือช่วยคนทำงาน แทนการทำงานเองอย่างสิ้นเชิง

## สรุป

ชุดข้อมูลนี้เหมาะสำหรับการนำไปใช้เป็นใบงาน/สั่งการบ้านในสถานศึกษา หรือแผนฝึกงาน 4 เดือน โดยมีโจทย์มากกว่า 200 รายการ และสามารถใช้งาน AI ฟรีเพื่อสร้างผลงานได้ทันที
