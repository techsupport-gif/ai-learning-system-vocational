# AI Project Lab สำหรับนักศึกษาฝึกงาน ปวช. คอมพิวเตอร์

## ภาพรวม

AI Project Lab เป็นระบบการเรียนรู้และฝึกสั่งงาน AI แบบมืออาชีพ สำหรับนักศึกษาฝึกงาน หลักสูตรประกาศนียบัตรวิชาชีพ (ปวช.) สาขาคอมพิวเตอร์ โดยมุ่งเน้นให้ผู้เรียน:

- ใช้ AI ฟรีเป็นผู้ช่วยในกระบวนการออกแบบและพัฒนาโปรเจกต์
- ฝึกการเขียน Prompt ที่ชัดเจนและมีโครงสร้าง
- ทำโปรเจกต์จริงที่ใช้งานได้จริง และสามารถนำเสนอได้
- พัฒนาทักษะด้านเว็บไซต์ เกม โปรแกรม AI และข้อมูล
- เกิดแรงบันดาลใจในการสร้างผลงานที่น่าสนใจและมีศักยภาพ

## จุดเด่น

- โจทย์ให้เลือกมากกว่า 100 แบบ
- ครอบคลุมหลายหมวด: เว็บ เกม โปรแกรม AI ธุรกิจ ไอที รายงาน สร้างสรรค์
- ใช้ได้ทันทีแบบ offline บนคอมพิวเตอร์ส่วนตัว
- จัดทำเป็นหน้าเว็บไซต์ที่มีดีไซน์มืออาชีพ
- มี Prompt Guide และแบบฟอร์มรายงานใช้งานจริง
- เหมาะสำหรับครู นักศึกษาฝึกงาน และการสอนแบบผสมผสาน AI

## การใช้งาน

1. เปิดไฟล์ `ai-project-lab/index.html` ในเว็บเบราว์เซอร์
2. เลือกหมวดงานและระดับความยาก
3. สุ่มโจทย์และคัดลอก Prompt ไปสั่ง AI
4. ปรับปรุงผลงานให้สวยและใช้งานได้จริง
5. จัดทำรายงานตามเทมเพลตที่มีให้

## ตัวอย่าง Prompt ภาษาไทย

“ช่วยสร้างเว็บไซต์สำหรับนักเรียน ปวช. เรื่องร้านกาแฟสไตล์วัยรุ่น 3 หน้า ใช้ HTML CSS JS เปิดได้ทันทีบน browser มีเมนูหน้าแรก โปรโมชั่น และติดต่อ”

“สร้างเกมตอบคำถามเรื่องไอทีแบบ browser ใช้ JavaScript มีเวลา 30 วินาที คะแนนและปุ่มเล่นใหม่ เมื่อจบเกมแสดงผลลัพธ์”

“สร้างแอปบันทึกค่าใช้จ่ายรายวันของนักเรียน ให้เพิ่ม ลบ แก้ไข และคำนวณยอดรวมแบบมือถือ”

## ตัวอย่าง Prompt ภาษาอังกฤษ

“Create a modern responsive coffee shop landing page for teenagers using HTML, CSS, and JavaScript. Include hero section, menu, promotions, and contact form.”

“Build a simple browser game for students with a timer, score system, multiple-choice questions, and restart feature.”

“Create a personal expense tracker web app with add, edit, delete, category selection, and daily summary.”

## หมวดโจทย์ที่ครอบคลุม

- เว็บ/เว็บไซต์
- โปรแกรม/แอป
- เกม
- AI & สื่อ
- Social Media
- ธุรกิจและการตลาด
- ไอทีและงานซ่อมบำรุง
- รายงานและข้อมูล
- งานสร้างสรรค์และความบันเทิง

## แนวทางสำหรับครูและผู้ดูแล

- ให้เด็กเลือก 1 โครงการหลักและ 1 โครงการเสริม
- ใช้ AI เป็นเครื่องมือช่วย ไม่ใช่คนทำแทน
- บันทึกประสิทธิภาพการใช้ AI และกระบวนการปรับปรุงผลงาน
- ให้คะแนนจากฟังก์ชัน ความสวยงาม รายงาน และความคิดสร้างสรรค์

## รายงานส่งงาน

นักศึกษาควรส่งผลงานในรูปแบบต่อไปนี้:

- ไฟล์โค้ดทั้งหมด
- ภาพหน้าจอหรือคลิปสาธิต
- รายงานภาษาไทย
- Prompt ที่ใช้สั่ง AI
- บันทึกสิ่งที่เรียนรู้และปัญหาที่พบ

## สรุป

AI Project Lab เป็นชุดพัฒนาและฝึกงาน AI ที่มีความครบถ้วนและพร้อมใช้งานจริงสำหรับโรงเรียนและหลักสูตร ปวช. คอมพิวเตอร์ โดยแยกเนื้อหาออกเป็นส่วนที่ชัดเจนและมีโครงสร้างเป็นมืออาชีพ เพื่อให้ครูและนักศึกษาใช้งานได้ทันทีและมีประสิทธิภาพสูงสุด
