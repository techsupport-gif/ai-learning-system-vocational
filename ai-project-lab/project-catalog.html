Prompt Guide: วิธีสั่ง AI ให้ได้ผลงานตรงตามต้องการ

หลักการสั่ง AI

  • ระบุวัตถุประสงค์ชัดเจน
  • ระบุประเภทผลงาน เช่น เว็บ เกม โปรแกรม
  • ระบุฟังก์ชันและหน้าที่ต้องการ
  • ระบุสไตล์ เช่น เท่ สวย เหมาะกับวัยรุ่น
  • ระบุข้อจำกัด เช่น HTML CSS JS, responsive, browser friendly
  • ระบุภาษาให้ชัดเจน เช่น ภาษาไทยหรือภาษาอังกฤษ

โครงสร้าง prompt ที่ดี

“สร้าง[ประเภทผลงาน]สำหรับ[กลุ่มเป้าหมาย] โดยมี[ฟังก์ชันหลัก] ใช้[เทคโนโลยี] ให้[สไตล์และความต้องการ] ผลลัพธ์ต้อง[ข้อกำหนด]”

ตัวอย่าง prompt ที่ใช้งานได้จริง

ตัวอย่าง 1

“ช่วยสร้างเว็บไซต์แนะนำสถานที่ท่องเที่ยวในจังหวัดสุพรรณบุรี ให้เป็นเว็บไซต์ 3 หน้า ใช้ HTML CSS JS มีปุ่มเลือกหมวด และภาพสวย เหมาะกับมือถือ”

ตัวอย่าง 2

“สร้างเกมตอบคำถามเรื่องไอทีแบบ browser ใช้ JavaScript มีเวลา 30 วินาที คะแนนระดับง่าย กลาง ยาก และปุ่มเล่นใหม่เมื่อจบเกม”

ตัวอย่าง 3

“สร้างแอปบันทึกค่าใช้จ่ายรายวันของนักเรียน ให้บันทึกรายการ แก้ไข ลบ และคำนวณยอดรวม แบบมือถือเป็นหลัก ใช้ HTML CSS JS”

เทคนิคที่ควรรู้

  • อย่าสั่ง AI แบบสั้นเกินไป
  • ให้ AI กำหนดโครงสร้างงานก่อนเขียนโค้ด
  • ระบุว่าต้องการโค้ดที่ใช้งานได้ทันทีหรือโครงร่างก่อน
  • ให้ AI อธิบายปัญหาและวิธีแก้ไข
  • ทดสอบทุกอย่างเองหลังคัดลอกโค้ด

สูตรสั้นที่ทำงานได้

“สร้าง[งาน]ให้เหมาะกับ[กลุ่ม] มี[ฟังก์ชัน] ใช้[เทคโนโลยี] และมี[สไตล์/ข้อจำกัด]”
