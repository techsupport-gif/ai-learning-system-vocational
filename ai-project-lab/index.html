# AI Project Lab สำหรับนักศึกษาฝึกงาน ปวช. คอมพิวเตอร์ ระบบสั่งงาน AI แบบใช้งานจริง เพื่อให้ครูและนักศึกษาฝึกงานสามารถใช้งานได้ทันที โดยมีวัตถุประสงค์หลักดังนี้: - ใช้ AI ฟรีเป็นเครื่องมือช่วยในการสร้างผลงานจริง - ฝึกทักษะการสั่งงาน AI อย่างเป็นระบบ - สร้างโจทย์ที่หลากหลาย เหมาะกับนักศึกษารุ่นเยาว์ - มีงานที่สนุกและนำไปอวดเพื่อน อาจารย์ และผู้สัมภาษณ์ได้ - เหมาะกับการทำฝึกงาน 4 เดือน และส่งผลงานในรูปแบบรายงานภาษาไทย ## โครงสร้างโปรเจกต์ - README.md - ai-project-lab/index.html - ai-project-lab/assignment-sheet.html - ai-project-lab/prompt-guide.html - ai-project-lab/project-catalog.html - ai-project-lab/teacher-guide.html - ai-project-lab/styles.css - ai-project-lab/script.js ## หน้าเว็บไซต์ที่พร้อมใช้งาน 1. หน้าแรก: หน้าแนะนำระบบและสุ่มโจทย์ 2. ใบงาน: รายละเอียดงานและกติกา 3. Prompt Guide: วิธีสั่ง AI ให้ได้ผลตรงตามที่ต้องการ 4. Project Catalog: คลังโจทย์งานหลายหมวด 5. Teacher Guide: แนวทางให้ครูประเมินและสั่งงาน ## เครื่องมือ AI ฟรีที่แนะนำ - ChatGPT - Gemini - Claude - DeepSeek - Perplexity - Copilot - OpenRouter - Codeium - Canva AI - Leonardo AI - Microsoft Designer - CapCut AI - Replit AI - Hugging Face - Ollama / LM Studio ## หมวดโจทย์ที่ครอบคลุม - เว็บ/เว็บไซต์ - โปรแกรม/แอป - เกม - AI และสื่อ - Social Media - ธุรกิจและการตลาด - ไอทีและงานซ่อมบำรุง - งานวิจัยและรายงาน - งานสร้างสรรค์และความบันเทิง ## ตัวอย่างโจทย์ที่นักศึกษาสามารถเลือกทำ - สร้างเว็บไซต์ร้านกาแฟสไตล์วัยรุ่น - สร้างเกมตอบคำถามเรื่องไอที - สร้างแอปบันทึกค่าใช้จ่ายรายวัน - สร้าง AI ช่วยสรุปบทเรียน - สร้างเว็บไซต์ร้านค้าออนไลน์ - สร้างแอปตรวจสอบความเร็วอินเทอร์เน็ต - สร้างเกมจับคู่ภาพ - สร้าง AI สร้างคอนเทนต์ TikTok - สร้าง dashboard สำหรับรายงานข้อมูล - สร้างแอปจัดการเวลาการเรียนและงานกลุ่ม ## แนวทางการใช้งาน - ให้เลือกอย่างน้อย 1 โครงการหลักและ 1 โครงการเสริม - ใช้ AI เป็นผู้ช่วย ไม่ใช่คนทำแทน - ต้องปรับปรุงโค้ดและดีไซน์เอง - ทำรายงานภาษาไทยพร้อมภาพหน้าจอ - บันทึก Prompt ที่ใช้และสรุปสิ่งที่เรียนรู้ ## ตัวอย่าง prompt ภาษาไทย “สร้างเว็บไซต์สำหรับนักเรียน ปวช. เรื่องร้านกาแฟสไตล์วัยรุ่น 3 หน้า ใช้ HTML CSS JS เปิดได้ทันทีใน browser มีเมนู หน้าแรก โปรโมชั่น เกี่ยวกับร้าน และติดต่อ” “สร้างเกมตอบคำถามเรื่องไอทีแบบ browser ใช้ JavaScript มีเทมเพลตสวย มีคะแนนและบอกผลสุดท้าย” “สร้างแอปบันทึกค่าใช้จ่ายรายวัน ใช้ HTML CSS JavaScript ให้สามารถเพิ่ม ลบ แก้ไข และคำนวณยอดรวม” ## ตัวอย่าง prompt ภาษาอังกฤษ “Create a responsive modern coffee shop landing page for teenagers with HTML, CSS, and JavaScript. Include hero section, menu, promotions, and contact form.” “Build a simple browser game for students with a timer, score board, multiple-choice questions, and restart button.” “Create a personal expense tracker web app with add, edit, delete, category selection, total calculation, and daily summary.” ## ข้อแนะนำสำหรับครู - ให้เด็กเลือกโจทย์ที่ตรงความสนใจ - ชักชวนให้ทำงานที่มีความน่าติดตามและนำไปอวดได้ - สอนนักศึกษาว่าการสั่ง AI ต้องมีโครงสร้างและมีจุดมุ่งหมาย - ให้คะแนนจากประสิทธิภาพ การใช้งาน ความสวยงาม และรายงาน ## แนะนำการส่งงาน นักศึกษาควรส่งงานในรูปแบบต่อไปนี้: - ไฟล์โค้ดทั้งหมด - ภาพหน้าจอหรือสกรีนช็อต - รายงานภาษาไทย - Prompt ที่ใช้สั่ง AI - บันทึกสิ่งที่ได้เรียนรู้และปัญหาที่พบ ## สรุป ชุดนี้สามารถเปิดใช้งานได้ทันทีบนเครื่องคอมพิวเตอร์ส่วนตัว โดยไม่ต้องใช้ server ภายนอก และเหมาะสำหรับการฝึกงาน การเรียนรู้ AI การพัฒนาโปรเจกต์ และการฝึกสั่งงาน AI ให้กับนักศึกษา ปวช. อย่างเป็นระบบ
